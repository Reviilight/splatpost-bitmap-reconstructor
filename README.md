# Splatpost Bitmap Reconstructor
<img src="assets/icons/SBR%20icon.png" alt="An icon of the tool on which you can see rough estimation of what it does." height="64" align="right">
A web app that helps reconstruct the original, pixel-perfect bitmap from an automatically saved image of a post from Splatoon games.

## Features
- [x] Reconstruct landscape and portrait images
- [x] A threshold to fine-tune the result
- [ ] Options to modificate the result
- [ ] Batch mode
## Stack
- HTML/CSS
- JavaScript
